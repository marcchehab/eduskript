# Willkommen bei Eduskript

Als Lehrperson bekommst du eine **öffentliche Webseite**, genau wie eduskript.org. Darauf platzierst du deine **Skripts**, die aus **Seiten** bestehen. Unten also:
- **<span class="es-color-green">'Erste Schritte' (grün)</span>** ist das Skript
- **<span class="es-color-orange">'Willkommen bei Eduskript' (orange)</span>** ist die erste Seite dieses Skripts
- <span class="es-color-blue">'Benutzerhandbuch'</span> ist eine Sammlung von Skripts. Sie ist optional.

Um loszulegen, melde dich an und/oder **<span class="es-color-red">klicke auf deinen Profil-Button</span>**, um zum Dashboard zu gelangen.

![](frontpage.excalidraw.light.svg)

## Der Page Builder

**<span class="es-color-blue">Platziere Skripts auf deiner öffentlichen Seite (blau)</span>**, indem du sie **<span class="es-color-red">aus deiner Bibliothek (rot)</span>** hineinziehst.

**<span class="es-color-green">"View Public Page" (grün)</span>** bringt dich auf deine öffentliche Seite. Ein Klick auf den **<span class="es-color-violet">Skript-Namen öffnet den Editor, in dem du den Inhalt bearbeitest (violett)</span>**.

![](pagebuilder.excalidraw.light.svg)

## Der Page Editor

Oben bearbeitest du **<span class="es-color-red">Eigenschaften des ganzen Skripts (rot)</span>**. Unter **<span class="es-color-violet">Pages findest du alle Seiten (violett)</span>** dieses Skripts, die du mit einem Klick **<span class="es-color-blue">im Page Editor darunter (blau)</span>** bearbeitest. Wenn du Änderungen speicherst, bringt dich das **<span class="es-color-orange">Augen-Symbol direkt auf deine öffentliche Seite (orange)</span>**.

![](page-editor.excalidraw.light.svg)
