# Inhaltslizenz

Eduskript verwendet zwei Lizenzen mit einer einfachen Grenze:

- **Quellcode** (alles im Git-Repository) → [AGPL v3](https://www.gnu.org/licenses/agpl-3.0.html)
- **Inhalte** (alles in der Datenbank) → [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/)

Das Speichermedium ist die Grenze. Code, Konfiguration und Dokumentation im Repository sind AGPL. Skripts, Seiten und alle von Nutzern erstellten Inhalte in der Datenbank sind CC BY-NC-SA. Inhalte, die in beiden existieren (etwa in die Plattform importierte Dokumentation), sind doppelt lizenziert — AGPL im Repo, CC BY-NC-SA in der Datenbank.

## Was CC BY-NC-SA 4.0 für deine Inhalte bedeutet

### Du behältst das Eigentum

Die Inhalte, die du erstellst, gehören dir. Die Lizenz regelt, wie andere sie verwenden dürfen — sie überträgt kein Eigentum.

### Keine kommerzielle Nutzung

Niemand darf deine Inhalte für kommerzielle Zwecke verwenden. Bezahlte Kurse, kommerzielle Lehrbücher und gewinnorientierte Schulungsunterlagen, die auf deiner Arbeit aufbauen, sind nicht erlaubt.

### Share-alike (Copyleft)

Wer auf deinen Inhalten aufbaut, muss seine Version unter denselben Bedingungen lizenzieren. Deine Arbeit bleibt offen — sie kann nicht in ein geschlossenes, proprietäres Produkt verwandelt werden.

### Namensnennung

Wer deine Inhalte verwendet oder darauf aufbaut, muss dich nennen. Auf Eduskript erledigt das die Plattform automatisch — geforkte Skripts zeigen einen «Forked from»-Link zum Original. Keine manuelle Namensnennung nötig.

## Forken und Kopieren

Eduskript erlaubt Lehrpersonen, die veröffentlichten Werke anderer zu forken. Wenn du ein Skript forkst:

- Erhältst du deine eigene unabhängige Kopie, die du frei bearbeiten kannst
- Bleibt das Original unverändert
- Erbt deine Version die CC BY-NC-SA-Lizenz (von der Share-alike-Klausel verlangt)
- Wird automatisch ein «Forked from»-Link angezeigt, der die Pflicht zur Namensnennung erfüllt

So lässt sich leicht auf der Arbeit anderer aufbauen — einer Kollegin, einer völlig fremden Person, einer Lehrperson in einem anderen Land. Passe eine Lektion an deine Klasse an, übersetze sie, erweitere sie mit neuen Übungen oder schlage eine ganz andere Richtung ein. Der ursprüngliche Autor muss dich weder kennen noch eine Erlaubnis erteilen; die CC BY-NC-SA-Lizenz deckt das bereits ab.

### Herkunft

Jedes geforkte Skript speichert einen Link zum Skript, von dem es geforkt wurde — ähnlich wie GitHub Forks nachverfolgt. Das dient zwei Zwecken:

1. **Auffindbarkeit** — du siehst, woher ein Skript stammt, und findest die Upstream-Version
2. **Namensnennung** — der Fork-Link erfüllt die Namensnennungspflicht von CC BY-NC-SA, sowohl auf der Plattform als auch als Referenz für alle, die Inhalte von der Plattform mitnehmen

Nur das unmittelbare Elternskript wird gespeichert. Wer weiter zurückverfolgen will, folgt den Links.

## Was du darfst

| Aktion | Erlaubt? |
|--------|----------|
| Das veröffentlichte Skript einer beliebigen Person forken und verändern | Ja |
| Geforkte Inhalte in deinen Klassen verwenden | Ja |
| Deinen Fork mit anderen Lehrpersonen auf Eduskript teilen | Ja |
| Deinen Fork auf deiner Eduskript-Seite veröffentlichen | Ja |

## Was du nicht darfst

| Aktion | Erlaubt? |
|--------|----------|
| Inhalte von Eduskript verkaufen | Nein |
| Sie in ein bezahltes Produkt aufnehmen | Nein |
| Die CC BY-NC-SA-Lizenz von einem Fork entfernen | Nein |
| Ausserhalb der Plattform ohne Namensnennung erneut veröffentlichen | Nein |

## Rollen bei der Zusammenarbeit

Wenn du ein Skript zur Bearbeitung mit einer Kollegin oder einem Kollegen teilst, wählst du zwischen zwei Rollen:

### Author

Co-Autoren teilen sich das gemeinsame Urheberrecht am Skript. Alle Autoren haben gleiche Rechte am Werk, unabhängig davon, wie viel jede Person beigetragen hat. Wähle diese Rolle für echte gemeinsame Erstellung, bei der beide Seiten das Skript von Anfang an zusammen aufbauen.

### Contributor

Contributors können das Skript genauso bearbeiten wie Autoren, aber ihre Änderungen werden den bestehenden Autoren unter CC BY-NC-SA 4.0 lizenziert. Contributors erwerben kein Urheberrecht. Wähle diese Rolle, wenn eine Kollegin oder ein Kollege dir hilft, deine Arbeit zu verbessern — Fehler korrigieren, eine Übung hinzufügen, Inhalte übersetzen.

> **Kurz gesagt**: Autoren besitzen das Werk gemeinsam. Contributors helfen daran mit.

Beide Rollen haben auf der Plattform dieselben Bearbeitungsrechte. Der Unterschied betrifft ausschliesslich, wem die entstehenden Inhalte gehören.

### Wann das eine Rolle spielt

Die Unterscheidung wird wichtig, wenn Inhalte die Plattform verlassen oder sich die Beteiligten trennen:

- **Autoren** können das gemeinsame Werk unabhängig forken, erneut veröffentlichen oder verbreiten (unter CC BY-NC-SA)
- **Contributors** behalten nach Entzug ihres Zugangs keinen Eigentumsanspruch
- Beim Forken eines gemeinsam verfassten Skripts ist die Zustimmung aller Autoren durch die CC BY-NC-SA-Lizenz abgedeckt

Beim Hinzufügen einer mitarbeitenden Person zeigt die Oberfläche:

> _"Authors share ownership of the content. Contributors help edit but don't gain ownership."_

## Warum diese Lizenzen?

**AGPL v3 für Code** — jeder kann eine eigene Eduskript-Instanz forken und betreiben, muss aber seine Änderungen teilen. So bleibt die Plattform Open Source.

**CC BY-NC-SA 4.0 für Inhalte** — weit verbreitet und in vielen Rechtsordnungen juristisch erprobt. Sie bietet:

- **Wenig Reibung** — die Plattform automatisiert die Namensnennung, Forken läuft nahtlos
- **Schutz** — kommerzielle Nutzung und Closed-Source-Ableitungen sind untersagt
- **Das Ökosystem bleibt offen** — die Share-alike-Klausel stellt sicher, dass Ableitungen offen bleiben
- **Herkunft** — Fork-Links erhalten eine nachvollziehbare Geschichte, woher Inhalte stammen

Wer die Eduskript-Codebasis forkt, erhält die Software unter AGPL (inklusive aller Docs im Repo). Wer Inhalte auf der Plattform liest, erhält sie unter CC BY-NC-SA. Die beiden Lizenzen decken verschiedene Bereiche ab und stehen nicht im Konflikt.

## Zusammenfassung

Eduskripts Code ist AGPL v3, Inhalte sind CC BY-NC-SA 4.0. Die Grenze ist das Speichermedium — Repo vs. Datenbank. Du behältst das Eigentum an deinen Inhalten. Andere können deine Arbeit für nicht-kommerzielle Zwecke forken und anpassen, wobei die Plattform die Namensnennung automatisch erledigt. Das Ökosystem bleibt offen.
